Правило

Второй тип описывает нереальное или маловероятное условие в настоящем или будущем. В русском — «если бы…, то…».

If + Past Simple, would + V
  • If I had money, I would buy a house.Если бы у меня были деньги, я бы купил дом (но их нет).
  • If I were you, I wouldn't do that.На твоем месте я бы этого не делал.
  • What would you do if you won the lottery?Что бы ты сделал, если бы выиграл?
  • If he knew her number, he could call her.could / might вместо would.

1 тип или 2 тип

1 тип: реально2 тип: нереально
If I have time, I'll help you. (возможно, будет время)If I had time, I'd help you. (времени нет)
Для всех лиц можно использовать were: If I were…, If she were… — это норма письменной речи. В части с if would не ставится.

Упражнение 1

Поставьте глагол в нужную форму.

  1. If I (have) more money, I would buy a house.
  2. If I were you, I (not / do) that.
  3. If he (know) her number, he would call her.
  4. What would you do if you (win) the lottery?
  5. If she (be) taller, she could be a model.
  6. We (go) to the sea if we had a car.
  7. If I (can) fly, I would visit every country.
  8. I (help) you if I had time.
  9. If they (live) closer, we would see them more often.
  10. If it (not / be) so cold, we would go out.
