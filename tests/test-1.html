ТемаГлавное правило
Артиклиa / an — один из многих, впервые; the — известный, единственный; без артикля — общий смысл, имена, приемы пищи

some / any / nosome — утверждение и просьба; any — вопрос и отрицание; no — без not
much / manymany — исчисляемые; much — неисчисляемые; a few / a little — немного (достаточно)
Степени сравнения-er / the -est для коротких, more / the most для длинных; good — better — the best
